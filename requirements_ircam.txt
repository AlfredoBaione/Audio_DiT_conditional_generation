# requirements_ircam.txt  --  conditioned Audio DiT, IRCAM Linux servers
# =====================================================================
# Frozen from a WORKING venv (pip freeze --local): lists ONLY the packages
# installed on top of the shared `tf2.18` conda base. torch / numpy / librosa /
# transformers / scipy / matplotlib / tensorboard come from the base via
# --system-site-packages and are identical on every IRCAM machine.
#
# NOTE: protobuf is intentionally NOT pinned here. descript-audiotools declares
# protobuf<3.20, which conflicts with the protobuf==4.25.9 that CLAP needs at
# runtime, so pip refuses to resolve them together. The working setup installs
# this file first, then forces protobuf==4.25.9 afterwards (a non-blocking
# warning is expected and ignored). This is automated by install_env.sh.
#
# DO NOT install via "pip install -r requirements_ircam.txt" alone -> use
# install_env.sh, which: installs this file, forces protobuf==4.25.9, removes
# wandb (it drags in an old protobuf), and runs the import checks.
#
# Prereqs: venv created on tf2.18 and ACTIVE:
#   conda activate tf2.18
#   python -m venv --system-site-packages /data/anasynth_nonbp/baione/envs/genaudio_cond_env
#   source /data/anasynth_nonbp/baione/envs/genaudio_cond_env/bin/activate
#   bash install_env.sh
#
# Do NOT install torch separately: the base tf2.18 torch (CUDA 12.x) works on
# the 12.x machines.
# USE_TF=0 is set in code (training_cond.py / extract_conditions.py) so
# transformers does not pull TensorFlow.
# =====================================================================
